무궁화추모공원 봉안 활성화 기획 (수정안)

원불교 총부사업기관 「원창」 직영 확인 + 장사(葬事) 트렌드 평가 반영 개정 · 충남 논산 벌곡면 · 19,000기 규모

⭐ 최대 전환 — “외부 시설 활용” → “교단 자산 경영”
이 시설은 원불교 총부사업기관 「원창」이 운영하는 기관 중 하나로 확인되었다(내부, 2026-07-31). 법인 실체는 재단법인 무궁화공원랜드(설립 2008. 9. 3.), 실질 운영담당자가 원불교 교무다. 남의 시설을 연결하는 문제가 아니라 교단이 소유·운영하는 저이용 자산(19,000기 중 5%)의 경영 문제다. 저이용은 곧 원창의 운영 적자·교단 자산 사장이다. → 초안이 1순위로 둔 소유·운영 관계 규명은 해소되었고, 병목은 실행 거버넌스로 이동했다. 전략 A~I는 외부 협상 없이 원불교 내부 의사결정으로 실행 가능하다.
초안은 “실내 봉안당을 채운다”를 전제로 8개 전략을 짰으나, 장사 트렌드를 ‘리스크’에만 적고 전략에 반영하지 못한 결함이 있었다. 이 수정안은 ①원창 직영 사실과 ②시장 흐름(산분장 합법화·선호 역전·정책 이전)을 함께 전략의 축으로 끌어올린다.

01시장 진단 — 하락·상승을 함께 본다

초안의 ‘봉안 수요 구조적 하락’ 진단은 절반만 맞다.

방향내용출처
하락 — 선호 역전봉안 34.6% / 자연장 33.0% / 산분 22.3% / 매장 9.4% — 봉안은 자연장과 동률권통계청(2021)
하락 — 정책 이전산분 이용률 2020년 8.2% → 2027년 30% 목표(국가가 봉안→산분 이전)보건복지부(2022)
상승 — 사망자 급증 추가2020년 31만 → 2030년 40만+ → 2070년 70만(2.3배) → 절대 봉안 건수 유지·증가통계청(2021)
상승 — 공설 포화 추가공설 봉안 부족·신규 중단 → 사설 반사이익수급계획·언론
상승 — 만기 도래 추가기존 봉안 30~60년 만기 개시 → 재안치 신규시장업계 동향

→ 봉안은 저성장·안정 수요 시장이다. ‘채운다’가 아니라 ‘회전시키고, 산분·자연장을 관문으로 유입한다’가 맞다.

02목표 — 단일치 삭제, 3 시나리오

초안의 ‘10년 내 25~30%’는 현재 속도(연 약 167기)의 2.2~2.8배를 요구해 비현실적이다.

04전략 (재구성)

원창 직영이므로 전략 A~I는 외부 MOU·협상이 아니라 원불교 내부 의사결정 사항이다. 특히 A·B·I는 상대를 설득하는 과제가 아니라 교정원↔원창이 정하면 되는 과제로 성격이 바뀌어 난이도가 크게 내려간다.

#전략수정 내용우선
A공식 봉안처 지정 (교정원 고시) 내부결정원창 직영 확인됨 → 교정원↔원창 내부 지정·고시, 교도 우대 요율·전용 구역 (외부 MOU 아님)단기
B전무출신 봉안 연계열반 시 기본 봉안처, 원로 봉안 구역 → 성지·상징화중기
C교당·교구 안내 표준화부고·장례 매뉴얼에 시설·요율 안내, 교구별 담당단기
D생전예약·회원제60세+ 교도·지역 주민 분납·가족 패키지단기
E무연 시대 의례 지속 보장 재정의·핵심“후손이 없어도 교단이 100년간 재를 올린다”를 상품화 — 사설업체가 복제 불가능한 유일한 해자(moat)·가격 프리미엄 근거핵심
F산분·자연장을 단기 관문으로 신설산분장 합법화(2025)로 부지 내 합법 운영 가능. 현재는 납골당(봉안당)만 운영 — 산분·자연장은 미보유. 저비용 유입 관문으로 신설이 필요단기
G접근성 = 교당 로컬 추모 접점 이원물리적 안치(논산) ↔ 의례적 추모(전국 교당) 분리. 합동 열반기념제·위패 열람·온라인 추모. 교단만 가능 — 원거리를 약점→중립단기
H기간제 봉안 + 만기 후 자연장 전환 신설영구봉안=영구 관리부채. 15/30년 기간제 → 만기 후 부지 내 산분·자연장. 회전↑·관리비 지속수입·만기시장 대응중기
I요율·상품 투명화·홍보봉안/자연장/산골/기간제 구분·요율 공개, 명상적 공간 스토리텔링단기
핵심 관점 — 봉안 활성화는 분양이 아니라 교화의 연장이다. E(의례 지속)·G(로컬 추모)는 전국 교당 네트워크를 가진 교단만 구현할 수 있는 차별화 축이며, F(산분 관문)는 시장 흐름에 올라타는 유입 장치다.

05실행 로드맵

  • 단기(0~6개월) — 실행 거버넌스 정리(재단↔원창↔교정원↔교당) + 담당 교무·원창과 현황·요율·시설 구성(현재 납골당만) 파악 / 데이터_묘위 실측→3 시나리오 / 산분·자연장 신설(F) / 공식 봉안처 지정(A)·교당 안내 표준화(C)·생전예약 시범(D) / 교당 로컬 추모 접점 파일럿(G) / 대전권 일반 개방 마케팅
  • 중기(6개월~2년) — 재단 공식 지정(A)·전무출신 봉안 구역(B)·의례 지속 보장 상품화(E)·기간제 봉안(H)·요율 공개(I)
  • 장기(2년~) — 추모·명상 성지 포지셔닝, 만기 유골 재안치 시장 진입, 이원 추모 전국 확대

06리스크·전제

  • 실행 거버넌스 미정 → 관계는 확인됐으나 4주체 역할 분담이 새 병목.
  • 목표 과열 주의 — 원창 직영이라 “우리 시설이니 채워야 한다”는 당위가 비현실적 목표를 밀어붙일 수 있음 → 3 시나리오·외부 개방으로 상쇄.
  • 정책 역풍: 국가가 봉안→산분 이전을 밀고 있어 봉안 일변도는 위험 → F·H로 헤지.
  • 지역 정서: 2008년 벌곡면에서 원불교 생태공원묘지·납골당 추진이 문화재(신독재 김집 묘) 중복·주민 반대로 무산된 이력 → 현 시설 연속성·주민정서 확인, 개방 마케팅에 반영.
  • 과대 설계: 19,000기는 단독 수요로 완충 어려움 → 3 시나리오 + 회전(기간제) + 관문(산분)으로 대응.
